# Phase 0 — Product validation (no code)

Not a Claude Code task. Do this before Phase 1a.

- [ ] Pick one pilot tent-house business
- [ ] Get their current item catalog and rates (paper list or memory)
- [ ] Note how bookings are tracked today (register, WhatsApp, memory)
- [ ] Confirm how they message customers today — roughly what share
      use WhatsApp vs only normal SMS
- [ ] Confirm the owner/staff are comfortable doing everything on
      their phone (Android or iPhone?)
- [ ] Ask how they currently follow up on overdue returns — this is
      the core pain point the product should visibly fix
- [ ] Note typical rental duration (single day event? multi-day?) —
      confirms the `PER_DAY`/`PER_EVENT` rate model fits
- [ ] Confirm mobile numbers collected are correct/reachable on
      WhatsApp or SMS (not a landline or a second family member's number)
